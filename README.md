# Automation Framework

## Overview
This project is a test automation framework built using Python and Pytest.

## Objectives
- Automate web application test cases.
- Maintain reusable test utilities.
- Generate test execution reports.
- Support team collaboration through Git and GitHub.

## Tech Stack
- Python
- Pytest
- Selenium WebDriver
- Git
- GitHub
- pytest.html

## Test Modules
- Login
- Registration
- Search

## Setup
1. Install Python.
2. Create a virtual environment.
3. Install project dependencies.
4. Execute tests using Pytest.

## Execution
```bash
pytest
```

## Team Workflow
Each QA engineer works on a separate feature branch. Code changes are reviewed through Pull Requests before merging into the main branch.
